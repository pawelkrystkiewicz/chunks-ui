# Getting Started

## Installation

```bash
bun add chunks-ui motion
```

`motion` is an optional peer dependency (`^12.0.0`). Components work without it, but animations require it.

## Setup

Add the theme to the CSS file that imports Tailwind (e.g. `app/globals.css`):

```css
@import "tailwindcss";
@import "chunks-ui/theme.css";
```

Then import components as needed:

```tsx
import { Button, Input, Tabs } from "chunks-ui";
```

The theme CSS exposes OKLCH color tokens as CSS variables and registers them with Tailwind CSS v4 through `@theme`. Its `@source` tells Tailwind to scan the package for the classes the components use -- no plugin needed.

## Architecture

- **Headless layer:** `@base-ui/react` v1.2+ (includes Floating UI for positioning)
- **Styling:** Tailwind CSS v4 + CVA + `clsx` + `tailwind-merge`
- **Animation:** Motion v12+ (optional peer dependency)
- **Build:** tsup (ESM + CJS + `.d.ts`)
- **Compound pattern:** Components use `<X.Root>`, `<X.Trigger>`, `<X.Content>` patterns
- **Composition:** Base UI `render` prop, not `asChild`
