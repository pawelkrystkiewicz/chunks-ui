# Components

Every component in chunks-ui.

- [Accordion](/components/accordion) — Stacked collapsible sections.
- [Avatar](/components/avatar) — User image with initials fallback.
- [Breadcrumb](/components/breadcrumb) — Location within a page hierarchy.
- [Button](/components/button) — Button with variants, colors, loading state and icons.
- [Calendar](/components/calendar) — Standalone date grid with min/max bounds.
- [Card](/components/card) — Grouped content layout.
- [Checkbox](/components/checkbox) — Checked, unchecked and indeterminate states.
- [Chip](/components/chip) — Small label or tag, optionally removable.
- [ClearButton](/components/clear-button) — Small icon button for clearing values.
- [Collapsible](/components/collapsible) — A single togglable section.
- [Combobox](/components/combobox) — Autocomplete with filtering and multi-select chips.
- [CopyButton](/components/copy-button) — Copies a value to the clipboard.
- [DatePicker](/components/date-picker) — Calendar in a popover.
- [Dialog](/components/dialog) — Modal dialog with backdrop, title and description.
- [Drawer](/components/drawer) — Side or bottom sheet overlay.
- [Empty](/components/empty) — Empty state for lists, tables and search results.
- [Field](/components/field) — Form field with label, description and error.
- [IconButton](/components/icon-button) — Square button for a single icon.
- [Input](/components/input) — Text input with adornments and clear button.
- [InputCopy](/components/input-copy) — Read-only input with a copy button.
- [Label](/components/label) — Standalone form label.
- [Loader](/components/loader) — Animated spinner.
- [Menu](/components/menu) — Dropdown menu with items, groups and radio groups.
- [NumberField](/components/number-field) — Numeric input with steppers and scrub area.
- [Pagination](/components/pagination) — Navigation for paginated content.
- [Popover](/components/popover) — Positioned popup with optional arrow.
- [Progress](/components/progress) — Determinate and indeterminate progress bar.
- [Radio](/components/radio) — Radio buttons and radio groups.
- [Resizable](/components/resizable) — Split panes with draggable, keyboard-operable handles.
- [ScrollArea](/components/scroll-area) — Scrollable container with overlay scrollbars.
- [Select](/components/select) — Single-select dropdown with grouped options.
- [Separator](/components/separator) — Horizontal or vertical divider.
- [Skeleton](/components/skeleton) — Pulsing loading placeholder.
- [Slider](/components/slider) — Draggable single-value or range input.
- [Switch](/components/switch) — Toggle switch.
- [Table](/components/table) — Styled HTML table.
- [Data Table](/components/data-table) — Data tables with TanStack Table; a recipe built on Table, not an export.
- [Tabs](/components/tabs) — Tabbed navigation with animated indicator.
- [Textarea](/components/textarea) — Multi-line input with optional auto-resize.
- [ThemeToggle](/components/theme-toggle) — Light/dark theme switch.
- [Toast](/components/toast) — Notifications triggered with `useToast`.
- [ToggleGroup](/components/toggle-group) — Toggle buttons, single or multiple.
- [Tooltip](/components/tooltip) — Hover and focus tooltip.
