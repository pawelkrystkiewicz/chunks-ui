# Components

Every component in chunks-ui, in sidebar order. Each page shows the import, live examples and the props.

- [Accordion](/components/accordion) — A vertically stacked set of collapsible sections built on Base UI's `Accordion` primitive.
- [Avatar](/components/avatar) — Displays a user avatar image with automatic fallback to initials.
- [Breadcrumb](/components/breadcrumb) — A navigation aid showing the user's location within a page hierarchy.
- [Button](/components/button) — A styled button built on Base UI's `Button` primitive, with visual variants, semantic colors, a loading state and start/end icons.
- [Calendar](/components/calendar) — A standalone date picker grid with controlled and uncontrolled selection, min/max bounds and disabled-date predicates.
- [Card](/components/card) — A compound layout component for displaying grouped content.
- [Checkbox](/components/checkbox) — A styled checkbox built on Base UI's `Checkbox` primitive, with checked, unchecked and indeterminate states.
- [Chip](/components/chip) — A small label/tag component with optional remove functionality.
- [ClearButton](/components/clear-button) — A small circular icon button for clearing or dismissing values.
- [Collapsible](/components/collapsible) — A single togglable section built on Base UI's `Collapsible` primitive.
- [Combobox](/components/combobox) — A styled autocomplete built on Base UI's `Combobox` primitive, with filtering, grouped options and multi-select with chips.
- [CopyButton](/components/copy-button) — A button that copies a value to the clipboard and shows a brief confirmation.
- [DatePicker](/components/date-picker) — A trigger-and-popover date picker built on Base UI's `Popover` primitive and the `Calendar` component.
- [Dialog](/components/dialog) — A modal dialog built on Base UI's `Dialog` primitive, with a backdrop, title and description.
- [Drawer](/components/drawer) — A side or bottom sheet overlay built on Base UI's `Dialog` primitive.
- [Empty](/components/empty) — A structured empty state for lists, tables and search results.
- [Field](/components/field) — A form field wrapper built on Base UI's `Field` primitive, with label, description, error message and validation state.
- [IconButton](/components/icon-button) — A compact, square button for a single icon, sharing Button's `variant` and `color` system.
- [Input](/components/input) — A styled text input built on Base UI's `Input` primitive, with start/end adornments, a clear button and error states.
- [InputCopy](/components/input-copy) — A read-only input with an integrated copy button.
- [Label](/components/label) — A standalone form label with consistent typography, for use outside a `Field`.
- [Loader](/components/loader) — An animated SVG spinner for loading states.
- [Menu](/components/menu) — A dropdown menu built on Base UI's `Menu` primitive, with plain items, groups, checkbox items and radio groups.
- [NumberField](/components/number-field) — A numeric input built on Base UI's `NumberField` primitive, with increment/decrement buttons, min/max/step constraints and a scrub area.
- [Pagination](/components/pagination) — A navigation component for paginated content, using semantic HTML.
- [Popover](/components/popover) — A positioned popup built on Base UI's `Popover` primitive, with an optional arrow.
- [Progress](/components/progress) — A progress bar built on Base UI's `Progress` primitive, with determinate and indeterminate states.
- [Radio](/components/radio) — Radio buttons built on Base UI's `Radio` and `RadioGroup` primitives.
- [ScrollArea](/components/scroll-area) — A custom scrollable container built on Base UI's `ScrollArea` primitive, with styled overlay scrollbars.
- [Select](/components/select) — A styled single-select dropdown built on Base UI's `Select` primitive, with grouped options.
- [Separator](/components/separator) — A visual divider built on Base UI's `Separator` primitive, horizontal or vertical.
- [Skeleton](/components/skeleton) — A placeholder loading indicator with a CSS-only pulse animation.
- [Slider](/components/slider) — A draggable range input built on Base UI's `Slider` primitive, for single values and ranges.
- [Switch](/components/switch) — A toggle switch built on Base UI's `Switch` primitive.
- [Table](/components/table) — A compound styling component for HTML tables.
- [Data Table](/components/data-table) — A recipe for building data tables with TanStack Table and the `Table` component.
- [Tabs](/components/tabs) — A tabbed navigation component built on Base UI's `Tabs` primitive, with an animated indicator.
- [Textarea](/components/textarea) — A multi-line text input with optional auto-resize.
- [ThemeToggle](/components/theme-toggle) — A controlled button for switching between light and dark themes.
- [Toast](/components/toast) — A notification system built on Base UI's `Toast` primitive, triggered with the `useToast` hook.
- [ToggleGroup](/components/toggle-group) — A group of toggle buttons where one or multiple items can be pressed at a time.
- [Tooltip](/components/tooltip) — A hover/focus tooltip built on Base UI's `Tooltip` primitive.
