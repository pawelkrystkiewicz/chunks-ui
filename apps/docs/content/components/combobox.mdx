# Combobox

A styled autocomplete/combobox built on Base UI's `Combobox` primitive. Includes text input with built-in filtering, popup with items, grouped options, multi-select with chips, and built-in Floating UI positioning.

## Import

```tsx
import { Combobox } from "chunks-ui";
```

## Basic Usage

```tsx
const fruits = [
  { value: "apple", label: "Apple" },
  { value: "banana", label: "Banana" },
  { value: "cherry", label: "Cherry" },
];

<Combobox.Root items={fruits}>
  <div className="relative">
    <Combobox.Input placeholder="Search a fruit..." aria-label="Fruit" />
    <Combobox.Trigger />
  </div>
  <Combobox.Portal>
    <Combobox.Positioner>
      <Combobox.Popup>
        <Combobox.List>
          {(item) => (
            <Combobox.Item key={item.value} value={item}>
              {item.label}
              <Combobox.ItemIndicator />
            </Combobox.Item>
          )}
        </Combobox.List>
        <Combobox.Empty>No results found.</Combobox.Empty>
      </Combobox.Popup>
    </Combobox.Positioner>
  </Combobox.Portal>
</Combobox.Root>
```

</Container>

`Combobox.Empty` shows when no item matches the input. Set `items` (or `filteredItems`) on `Combobox.Root`, or it always shows.

Pass each item object as the `Combobox.Item` `value`. Base UI shows an object's `label` in the input and submits its `value` with a form, so picking "Banana" fills the input with "Banana". For other object shapes, set `itemToStringLabel` (and `itemToStringValue` for forms) on `Combobox.Root`. If you pass the selected value in from elsewhere (`value`/`defaultValue`) and it isn't the same object as the item, set `isItemEqualToValue`.

## Grouped Options

Pass groups (`{ value, items }`) as `items`. `Combobox.List` then calls its child once per group, with only the group's matching items, and hides empty groups while filtering:

```tsx
const colors = [
  {
    value: "Warm",
    items: [
      { value: "red", label: "Red" },
      { value: "orange", label: "Orange" },
      { value: "yellow", label: "Yellow" },
    ],
  },
  {
    value: "Cool",
    items: [
      { value: "blue", label: "Blue" },
      { value: "green", label: "Green" },
      { value: "purple", label: "Purple" },
    ],
  },
];

<Combobox.Root items={colors}>
  <div className="relative">
    <Combobox.Input placeholder="Pick a color..." aria-label="Color" />
    <Combobox.Trigger />
  </div>
  <Combobox.Portal>
    <Combobox.Positioner>
      <Combobox.Popup>
        <Combobox.List>
          {(group: (typeof colors)[number]) => (
            <Combobox.Group key={group.value} items={group.items}>
              <Combobox.GroupLabel>{group.value}</Combobox.GroupLabel>
              {group.items.map((item) => (
                <Combobox.Item key={item.value} value={item}>
                  {item.label}
                  <Combobox.ItemIndicator />
                </Combobox.Item>
              ))}
            </Combobox.Group>
          )}
        </Combobox.List>
        <Combobox.Empty>No results found.</Combobox.Empty>
      </Combobox.Popup>
    </Combobox.Positioner>
  </Combobox.Portal>
</Combobox.Root>
```

## Multi-Select with Chips

```tsx
type Framework = { value: string; label: string };

function MultiSelectCombobox() {
  const [value, setValue] = useState<Framework[]>([]);

  return (
    <Combobox.Root multiple items={frameworks} value={value} onValueChange={setValue}>
      <Combobox.Control>
        <Combobox.Chips className="flex-1">
          {value.map((item) => (
            <Combobox.Chip key={item.value}>
              {item.label}
              <Combobox.ChipRemove />
            </Combobox.Chip>
          ))}
          <Combobox.Input
            className="h-7 min-w-20 flex-1 border-0 bg-transparent px-0"
            placeholder="Select frameworks..."
            aria-label="Frameworks"
          />
        </Combobox.Chips>
        <Combobox.Clear />
        <Combobox.Trigger />
      </Combobox.Control>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.List>
              {(item) => (
                <Combobox.Item key={item.value} value={item}>
                  {item.label}
                  <Combobox.ItemIndicator />
                </Combobox.Item>
              )}
            </Combobox.List>
            <Combobox.Empty>No results found.</Combobox.Empty>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  );
}
```

<Container>

</Container>

Put `Combobox.Input` inside `Combobox.Chips`, after the chips. Only there does the keyboard reach the chips: ArrowLeft (ArrowRight in a right-to-left layout) at the start of the input focuses the last chip, and Backspace in an empty input removes it.

## Animation

The popup enters with a scale-up and fade (from `scale-95` and `opacity-0`): the `popup` spring (`springs.popup`) with Motion installed, a CSS transition of `opacity` and `scale` without it; reduced motion turns off both. The popup grows out of its trigger (`origin-(--transform-origin)`); a `className` such as `origin-top` replaces it.

`render` on `Combobox.Popup` replaces the element the spring animates, so a popup with `render` uses the CSS transition even with Motion installed. To restyle the popup, pass `className`.

## Compound Parts

| Part | Description |
|---|---|
| `Combobox.Root` | State container. Manages open/close, filtering, and selected value(s). |
| `Combobox.Control` | Bordered wrapper for multi-select (chips + input): Base UI's `Combobox.InputGroup`, a `role="group"` (pass `aria-label` to name it). The popup anchors to it, and a press on its padding focuses the input and opens the popup, unless `openOnInputClick` is false. `Combobox.Clear` and `Combobox.Trigger` sit over its end: its end padding (`pe-12`) keeps the chips and the input's text out from under them. A `px-*` or `p-*` class, with or without a variant such as `md:`, replaces it: add `pe-12` back. Draws the focus ring (`has-[:focus-visible]`) while the input or a chip inside it has keyboard focus, and turns off the ring of its combobox input, so one ring shows; a focused chip also draws its own. |
| `Combobox.Input` | Text input with built-in filtering. |
| `Combobox.Trigger` | Button that toggles the popup. Renders a default chevron icon. |
| `Combobox.Icon` | Chevron icon, usable standalone outside the trigger. |
| `Combobox.Portal` | Renders the popup in a portal. |
| `Combobox.Positioner` | Handles Floating UI positioning. Default `sideOffset={8}`, as on `Popover.Content` and `Menu.Content`: the input's focus ring, 4px outside its edge, stays clear of the popup. A `sideOffset` you pass replaces it, so `sideOffset={0}` opens the popup flush against the input. Inside a `Combobox.Control` the popup anchors to the Control: it is as wide as the Control and opens 8px below the Control's border. |
| `Combobox.Popup` | The dropdown panel containing items. It is as wide as the input, or as the `Combobox.Control` in a multi-select. Item text wraps to that width, and a word longer than the popup breaks. Scrolls when the items need more than the space between the input and the viewport edge. |
| `Combobox.List` | List container. Takes a function child that renders each matching item (or each group, when `items` holds groups). |
| `Combobox.Item` | An individual selectable option. |
| `Combobox.ItemIndicator` | Checkmark shown for the selected item. |
| `Combobox.Empty` | Message displayed when no items match the filter. Needs `items` on Root. |
| `Combobox.Clear` | Button that clears the current value. Renders a default X icon. |
| `Combobox.Group` | Groups related items together. |
| `Combobox.GroupLabel` | Label for a group of items. |
| `Combobox.Chips` | Container for selected chips in multi-select mode: a wrapping row with a 4px gap between the chips (`gap-1`; `className` merges with it). Takes ordinary children: map the selected values to `Combobox.Chip`s, and put `Combobox.Input` after them. Add `flex-1`, as the example does: the row is only as wide as its chips, so without it the input shrinks to its minimum width. |
| `Combobox.Chip` | A styled chip representing a selected value. Draws the focus ring when the arrow keys focus it. Arrow keys move focus from the input to a chip only when the input is inside `Combobox.Chips`. |
| `Combobox.ChipRemove` | Button to remove a chip. Renders a default X icon. |
| `Combobox.Value` | Displays the selected value. |
| `Combobox.Status` | Accessible status announcements for screen readers. |

## Accessible Names

`Combobox.Trigger`, `Combobox.Clear` and `Combobox.ChipRemove` show only an icon, so each one has a default name: "Show options", "Clear selection" and "Remove" followed by the text of its chip ("Remove Apple"). Pass [`labels`](#labels) to `Combobox.Root` to translate them, or `aria-label` to a part to use a different name:

```tsx
<Combobox.ChipRemove aria-label={`Deselect ${item.label}`} />
```

If you pass `children` or a `render` element, the default name and the default icon are not applied. The content you pass names the button, so give icon-only content an `aria-label`:

```tsx
<Combobox.Trigger render={<button type="button">Choose</button>} />
```

Inside `Field.Root`, Base UI sets `aria-labelledby` on `Combobox.Trigger` to the field label. That label takes precedence over `aria-label`, so the default "Show options" name does not apply there.

## Touch Targets

`Combobox.Clear` is 14px wide and `Combobox.Trigger` is 24px wide. To make the clear button easier to tap, add [`touch-target`](/utilities#touch-target) to it: its hit area grows to 44×44px, and the layout stays the same. The area also covers the last 15px of the input before the button. Keep `Combobox.Clear` before `Combobox.Trigger` in the DOM, as in the examples: the clear button's area covers part of the trigger, and DOM order makes the trigger paint above it.

```tsx
<div className="relative">
  <Combobox.Input placeholder="Search a fruit..." aria-label="Fruit" />
  <Combobox.Clear className="touch-target" />
  <Combobox.Trigger />
</div>
```

Add `touch-target` to `Combobox.Trigger` only when there is no `Combobox.Clear` next to it. Their centres are 23px apart, so the trigger's area would cover the end of the clear button, and a press there would open the popup.

## Props

All compound parts accept the same props as their underlying Base UI [`Combobox`](https://base-ui.com/react/components/combobox#api-reference) counterparts. `Combobox.Control` is Base UI's `Combobox.InputGroup` and accepts its props. `Combobox.Root` also takes `labels`:

## Labels

`labels` replaces the built-in English text, for example to translate it. Keys you leave out keep their default from `DEFAULT_COMBOBOX_LABELS`. An `aria-label` on a part takes precedence. See [Labels](/labels).
