# DatePicker

A trigger-and-popover date picker built on Base UI's `Popover` primitive and the `Calendar` component. Selecting a date closes the popover automatically.

## Import

```tsx
import { DatePicker } from "chunks-ui";
```

## Basic Usage

```tsx
<DatePicker />
```

<DatePickerBasicExample />

## Controlled

```tsx
function ControlledDatePicker() {
  const [date, setDate] = useState<Date | null>(null);

  return (
    <DatePicker
      value={date}
      onValueChange={setDate}
      placeholder="Select a date"
    />
  );
}
```

<DatePickerControlledExample />

## Date Constraints

Use `min` and `max` to limit the selectable range. Dates outside the range are rendered disabled in the calendar:

```tsx
const today = new Date();
const nextMonth = new Date(today.getFullYear(), today.getMonth() + 1, today.getDate());

<DatePicker min={today} max={nextMonth} />
```

## Week Start and Outside Days

`weekStartsOn` and `showOutsideDays` are passed to the calendar in the popover. See [Calendar](/components/calendar#week-start-and-outside-days) for what they do.

```tsx
<DatePicker weekStartsOn={1} showOutsideDays />
```

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on the trigger | Opens the calendar |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on a day | Selects the day, closes the calendar and returns focus to the trigger |
| <kbd>Escape</kbd> | Closes the calendar without changing the date and returns focus to the trigger |

When the calendar opens, focus goes to the selected day, or to today if no date is selected. Inside the calendar, the arrow, Home, End and Page keys move focus as described in [Calendar keyboard](/components/calendar#keyboard). Disabled days can take focus but cannot be selected.
