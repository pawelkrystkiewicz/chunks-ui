# Label

A standalone form label with consistent typography. Use when you need a label outside of a `Field` context. For labels inside a `Field.Root`, use `Field.Label` instead.

## Import

```tsx
import { Label } from "chunks-ui";
```

## Basic Usage

```tsx
<Label htmlFor="email">Email address</Label>
```

<Container>
  <Label htmlFor="email">Email address</Label>
</Container>

## With Input

```tsx
<div className="flex flex-col gap-1.5">
  <Label htmlFor="username">Username</Label>
  <input id="username" className="border rounded px-3 py-1.5 text-sm" />
</div>
```

<Container>
  <div className="flex flex-col gap-1.5">
    <Label htmlFor="username">Username</Label>
    <input id="username" className="rounded border px-3 py-1.5 text-sm" />
  </div>
</Container>

## Next to a Disabled Control

```tsx
<div className="flex items-center gap-2">
  <Label htmlFor="terms">Accept terms</Label>
  <Checkbox.Root id="terms" disabled>
    <Checkbox.Indicator />
  </Checkbox.Root>
</div>
```

<Container>
  <div className="flex items-center gap-2">
    <Label htmlFor="terms">Accept terms</Label>
    <Checkbox.Root id="terms" disabled>
      <Checkbox.Indicator />
    </Checkbox.Root>
  </div>
</Container>

The label dims when the element right after it, usually its control but any disabled element, is disabled.

It doesn't dim when:

- the control comes first (a native input with the `peer` class is the exception)
- other elements sit in between, such as an `Input` with adornments. Wrap each pair, or dim the label yourself, for example with `className={cn(disabled && "opacity-50")}`.

Inside a `Field.Root`, use `Field.Label`, which dims when the field is disabled.

## Props

This component accepts all props from the native `<label>` element.

## Styling

- `font-medium text-sm leading-none` — matches `Field.Label` typography
- `has-[+:disabled]:` and `has-[+[data-disabled]]:` set `opacity-50` and `cursor-not-allowed` when the control right after the label is disabled (see [Next to a Disabled Control](#next-to-a-disabled-control))
- `peer-disabled:cursor-not-allowed peer-disabled:opacity-50` — dims after a disabled native input with the `peer` class
