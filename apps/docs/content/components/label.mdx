# Label

A standalone form label with consistent typography. Use when you need a label outside of a `Field` context. For labels inside a `Field.Root`, use `Field.Label` instead.

## Import

```tsx
import { Label } from "chunks-ui";
```

## Basic Usage

```tsx
<Label htmlFor="email">Email address</Label>
```

<Container>
  <Label htmlFor="email">Email address</Label>
</Container>

## With Input

```tsx
<div className="flex flex-col gap-1.5">
  <Label htmlFor="username">Username</Label>
  <input id="username" className="border rounded px-3 py-1.5 text-sm" />
</div>
```

<Container>
  <div className="flex flex-col gap-1.5">
    <Label htmlFor="username">Username</Label>
    <input id="username" className="rounded border px-3 py-1.5 text-sm" />
  </div>
</Container>

## Next to a Disabled Control

The label dims (50% opacity, `not-allowed` cursor) next to a disabled control, in two layouts:

- **Label first:** the control is the label's next sibling. This works for a native `<input>`, `<textarea>` or `<select>`, `Input` without adornments, `Textarea`, and Base UI parts that set `data-disabled`, such as `Checkbox.Root` and `Switch.Root`.
- **Control first:** the control is an earlier sibling with the `peer` class. `Checkbox.Root`, `Switch.Root` and `Radio.Root` have it already. Add `className="peer"` to other controls.

```tsx
<div className="flex items-center gap-2">
  <Checkbox.Root id="terms" disabled>
    <Checkbox.Indicator />
  </Checkbox.Root>
  <Label htmlFor="terms">Accept terms</Label>
</div>
```

<Container>
  <div className="flex items-center gap-2">
    <Checkbox.Root id="terms" disabled>
      <Checkbox.Indicator />
    </Checkbox.Root>
    <Label htmlFor="terms">Accept terms</Label>
  </div>
</Container>

The label doesn't dim in other layouts: when it wraps the control, when the two have different parents, or when something else sits between them in the label-first layout. An `Input` with adornments is one such case, because the label's next sibling is then the wrapper around the input. Inside a `Field.Root`, use `Field.Label`, which dims when the field is disabled.

## Props

This component accepts all props from the native `<label>` element.

## Styling

- `font-medium text-sm leading-none` — matches `Field.Label` typography
- `opacity-50` and `cursor-not-allowed` next to a disabled control (see [Next to a Disabled Control](#next-to-a-disabled-control)), through `peer-disabled:` and `peer-data-disabled:` for a control before the label, and `has-[+:disabled]:` and `has-[+[data-disabled]]:` for a control right after it
