# CopyButton

A button that copies a value to the clipboard and shows a brief confirmation. Transitions from a clipboard icon to a check icon on click.

## Import

```tsx
import { CopyButton } from "chunks-ui";
```

## Basic Usage

```tsx
<CopyButton value="npm install chunks-ui" />
```

<CopyButtonBasicExample />

## Custom Children

Use the render-prop `children` for custom content. The `copied` boolean reflects the current state:

```tsx
<CopyButton value="REF-2024-XK9">
  {({ copied }) => (
    <span className="text-xs">{copied ? "Copied!" : "Copy code"}</span>
  )}
</CopyButton>
```

<CopyButtonCustomExample />

## Timeout

Control how long the "copied" confirmation persists with the `timeout` prop (default 2000ms):

```tsx
<CopyButton value="text" timeout={5000} />
```

All other props are forwarded to the underlying [`IconButton`](/components/icon-button), so `variant` and `color` work too. They default to `text` and `secondary`. With a `render` element and no `children`, the button draws no icon: the element draws its own, and may be a void element such as `<img>`. The button keeps its default name.

## Labels

`labels` replaces the built-in English text, for example to translate it. Keys you leave out keep their default from `DEFAULT_COPY_BUTTON_LABELS`. `aria-label` takes precedence and keeps one name in both states. With `children`, the button has no default name, so `labels` does not apply. The content names the button then, so icon-only `children` need an `aria-label`. See [Labels](/labels).
