# Drawer

A side or bottom sheet overlay built on Base UI's `Dialog` primitive. Slides in from the left, right, or bottom edge.

## Import

```tsx
import { Drawer } from "chunks-ui";
```

## Basic Usage

```tsx
<Drawer.Root>
  <Drawer.Trigger>Open Drawer</Drawer.Trigger>
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Popup>
      <Drawer.Title>Navigation</Drawer.Title>
      <Drawer.Description>Browse the app sections.</Drawer.Description>
      <nav className="mt-4 flex flex-col gap-2">
        <a href="/">Home</a>
        <a href="/theme">Theme</a>
      </nav>
      <Drawer.Close>Close</Drawer.Close>
    </Drawer.Popup>
  </Drawer.Portal>
</Drawer.Root>
```

## Side Variants

The `side` prop on `Drawer.Popup` controls which edge the drawer slides from:

```tsx
{/* Right side (default) */}
<Drawer.Popup side="right">...</Drawer.Popup>

{/* Left side */}
<Drawer.Popup side="left">...</Drawer.Popup>

{/* Bottom sheet */}
<Drawer.Popup side="bottom">...</Drawer.Popup>
```

- `left` and `right` drawers have a fixed width of `w-80`.
- `bottom` drawer spans the full width with automatic height (up to `80dvh`) and rounded top corners.
- Content taller than the drawer scrolls inside it. To keep the Title and the actions in place, put the content in a `Drawer.Body` (below).
- With long content and actions only at the bottom, Base UI focuses the first tabbable element and scrolls to it. Pass `initialFocus` a ref to a top element, such as the Close button or the Title with `tabIndex={-1}`, to open at the top.
- With nothing tabbable inside, or with `initialFocus` on the popup itself, the popup takes focus. When the browser shows focus there (after keyboard use, for example), the ring is 2px in `--ring` and drawn just inside the 1px border on the open side, 3px from the popup's edge, so the border stays visible.

## Long content

Put long content in a `Drawer.Body` between the Title and the actions. The Title, the Description and the actions stay in place, and only the Body scrolls. In a `left` or `right` drawer the Body fills the height, so the actions sit at the bottom edge; a `bottom` drawer grows with its content up to `80dvh`:

```tsx
<Drawer.Root>
  <Drawer.Trigger>Read the terms</Drawer.Trigger>
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Popup>
      <Drawer.Title>Terms of service</Drawer.Title>
      <Drawer.Description>Read the terms before you accept them.</Drawer.Description>
      <Drawer.Body className="mt-4 space-y-3 text-sm">
        <p>These terms apply to your use of the service.</p>
        <p>Keep your account details safe.</p>
      </Drawer.Body>
      <div className="mt-4 flex justify-end gap-2">
        <Drawer.Close render={<Button variant="outlined" color="secondary" />}>
          Cancel
        </Drawer.Close>
        <Drawer.Close render={<Button />}>Accept</Drawer.Close>
      </div>
    </Drawer.Popup>
  </Drawer.Portal>
</Drawer.Root>
```

`Drawer.Body` works as `Dialog.Body`: the tab stop, `data-overflowing`, the name from the Title and the form through `render`. See [Dialog](/components/dialog#form-in-a-body).

## Controlled

```tsx
function ControlledDrawer() {
  const [open, setOpen] = useState(false);

  return (
    <Drawer.Root open={open} onOpenChange={setOpen}>
      <Drawer.Trigger>Menu</Drawer.Trigger>
      <Drawer.Portal>
        <Drawer.Backdrop />
        <Drawer.Popup side="left">
          <Drawer.Title>Menu</Drawer.Title>
          <Drawer.Close>Close</Drawer.Close>
        </Drawer.Popup>
      </Drawer.Portal>
    </Drawer.Root>
  );
}
```

## Animation

The drawer slides in from its edge: on the x-axis for `left` and `right`, on the y-axis for `bottom`. With Motion installed it uses the `overlay` spring (`springs.overlay`). Without Motion it is a CSS transition (`micro-interactions`: 300ms on `--default-transition-timing-function`, by default `cubic-bezier(0.4, 0, 0.2, 1)`). Reduced motion turns off both. The backdrop fades in independently.

`render` on `Drawer.Popup` or `Drawer.Backdrop` replaces the element the spring animates, so a popup or backdrop with `render` uses the CSS transition even with Motion installed. To restyle either, pass `className`; to change the element of the content, put `render` on `Drawer.Body`.

## Compound Parts

| Part | Description |
|---|---|
| `Drawer.Root` | State container. Manages open/close state. |
| `Drawer.Trigger` | Button that opens the drawer. |
| `Drawer.Portal` | Renders children in a portal. Puts the drawer on the `z-drawers` (600) layer; popups, dialogs and drawers opened from it stack above it. |
| `Drawer.Backdrop` | Semi-transparent overlay. Also renders for a nested drawer, so it dims the parent. |
| `Drawer.Popup` | The sliding panel. Accepts `side` prop. |
| `Drawer.Title` | Drawer heading. |
| `Drawer.Description` | Supporting description text. |
| `Drawer.Body` | Optional scrolling area for long content, between the Title and the actions. Only the Body scrolls; the other parts stay in place. |
| `Drawer.Close` | Button that closes the drawer. |

## Drawer.Root Props

All `Drawer.Root` props are forwarded to the underlying Base UI [`Dialog`](https://base-ui.com/react/components/dialog#api-reference).

## Drawer.Body Props

`Drawer.Body` takes the props of `Dialog.Body`: a `<section>`'s, plus Base UI's `render`.
