# Drawer

A side or bottom sheet overlay built on Base UI's `Dialog` primitive. Slides in from the left, right, or bottom edge.

## Import

```tsx
import { Drawer } from "chunks-ui";
```

## Basic Usage

```tsx
<Drawer.Root>
  <Drawer.Trigger>Open Drawer</Drawer.Trigger>
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Popup>
      <Drawer.Title>Navigation</Drawer.Title>
      <Drawer.Description>Browse the app sections.</Drawer.Description>
      <nav className="mt-4 flex flex-col gap-2">
        <a href="/">Home</a>
        <a href="/settings">Settings</a>
      </nav>
      <Drawer.Close>Close</Drawer.Close>
    </Drawer.Popup>
  </Drawer.Portal>
</Drawer.Root>
```

## Side Variants

The `side` prop on `Drawer.Popup` controls which edge the drawer slides from:

```tsx
{/* Right side (default) */}
<Drawer.Popup side="right">...</Drawer.Popup>

{/* Left side */}
<Drawer.Popup side="left">...</Drawer.Popup>

{/* Bottom sheet */}
<Drawer.Popup side="bottom">...</Drawer.Popup>
```

- `left` and `right` drawers have a fixed width of `w-80`.
- `bottom` drawer spans the full width with automatic height (up to `80dvh`) and rounded top corners.
- Content taller than the drawer scrolls inside it.
- With long content and actions only at the bottom, Base UI focuses the first tabbable element and scrolls to it. Pass `initialFocus` a ref to a top element, such as the Close button or the Title with `tabIndex={-1}`, to open at the top.

## Controlled

```tsx
function ControlledDrawer() {
  const [open, setOpen] = useState(false);

  return (
    <Drawer.Root open={open} onOpenChange={setOpen}>
      <Drawer.Trigger>Menu</Drawer.Trigger>
      <Drawer.Portal>
        <Drawer.Backdrop />
        <Drawer.Popup side="left">
          <Drawer.Title>Menu</Drawer.Title>
          <Drawer.Close>Close</Drawer.Close>
        </Drawer.Popup>
      </Drawer.Portal>
    </Drawer.Root>
  );
}
```

## Animation

The drawer slides in from its edge: on the x-axis for `left` and `right`, on the y-axis for `bottom`. With Motion installed it uses the `overlay` spring (`springs.overlay`). Without Motion it is a CSS transition (`micro-interactions`: 300ms, `cubic-bezier(0.4, 0, 0.2, 1)`). Reduced motion turns off both. The backdrop fades in independently.

## Compound Parts

| Part | Description |
|---|---|
| `Drawer.Root` | State container. Manages open/close state. |
| `Drawer.Trigger` | Button that opens the drawer. |
| `Drawer.Portal` | Renders children in a portal. Puts the drawer on the `z-drawers` (600) layer; popups, dialogs and drawers opened from it stack above it. |
| `Drawer.Backdrop` | Semi-transparent overlay. Also renders for a nested drawer, so it dims the parent. |
| `Drawer.Popup` | The sliding panel. Accepts `side` prop. |
| `Drawer.Title` | Drawer heading. |
| `Drawer.Description` | Supporting description text. |
| `Drawer.Close` | Button that closes the drawer. |

## Drawer.Root Props

All `Drawer.Root` props are forwarded to the underlying Base UI [`Dialog`](https://base-ui.com/react/components/dialog#api-reference).
