# Textarea

A multi-line text input with optional auto-resize behavior using the CSS `field-sizing: content` property.

## Import

```tsx
import { Textarea } from "chunks-ui";
```

## Basic Usage

```tsx
<Textarea placeholder="Write your message..." />
```

<Container centered={false}>
  <Textarea placeholder="Write your message..." />
</Container>

## Auto-Resize

When `autoResize` is `true`, the textarea grows vertically to fit its content using the native CSS `field-sizing: content` property:

```tsx
<Textarea autoResize placeholder="Start typing..." />
```

<Container centered={false}>
  <Textarea autoResize placeholder="Start typing..." />
</Container>

The textarea has a minimum height of `min-h-ui-height` by default.

## With Field

`Textarea` is a field control, like `Input`. Inside `Field.Root`, `Field.Label` names it, `Field.Description` describes it, and `disabled` on the root disables it. When the field is invalid, the textarea gets `aria-invalid` and `data-invalid`, and the same red border as `Input`.

```tsx
<Field.Root>
  <Field.Label>Bio</Field.Label>
  <Field.Description>Write a short bio (max 280 characters)</Field.Description>
  <Textarea autoResize placeholder="Tell us about yourself..." maxLength={280} />
</Field.Root>
```

## Controlled Value

`Textarea` passes `value` and `defaultValue` through Base UI, like `Input`. A controlled `value` must be controlled from the first render, so never start with `undefined`. Use `value={bio ?? ""}`. Switching between controlled and uncontrolled after mount leaves the textarea empty and logs a warning in development, and changing `defaultValue` after mount logs an error.

```tsx
<Textarea value={bio ?? ""} onChange={(event) => setBio(event.target.value)} />
```

All other props are forwarded to the underlying `<textarea>` element. `className` can also be a function that gets the field state (`disabled`, `valid`, `touched`, `dirty`, `filled`, `focused`) and returns classes. `valid` is `false` when the field is invalid and `null` before validation.
