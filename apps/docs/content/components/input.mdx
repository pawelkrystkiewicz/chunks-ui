# Input

A styled text input built on Base UI's `Input` primitive. Supports start/end adornments, a clear button, and error states via `data-[invalid]`.

## Import

```tsx
import { Input } from 'chunks-ui'
```

## Basic Usage

```tsx
<Input placeholder="Enter your name" aria-label="Name" />
```

<Container>
  <Input placeholder="Enter your name" aria-label="Name" />
</Container>

## Adornments

Use `startAdornment` and `endAdornment` to place icons or text at the edges of the input:

```tsx
<Input startAdornment={<SearchIcon className="size-4" />} placeholder="Search..." aria-label="Search" />
```

<Container>
  <Input startAdornment={<SearchIcon className="size-4" />} placeholder="Search..." aria-label="Search" />
</Container>

```tsx
<Input endAdornment={<span className="text-xs text-muted-foreground">USD</span>} placeholder="0.00" aria-label="Amount" />
```

<Container>
  <Input endAdornment={<span className="text-xs text-muted-foreground">USD</span>} placeholder="0.00" aria-label="Amount" />
</Container>

## Clear Button

Pass an `onClear` callback to show a built-in clear button (uses the `ClearButton` component internally). The button appears only while a controlled `value` is not empty, so pair `onClear` with `value` and `onChange`; an uncontrolled input (`defaultValue`) never shows it. While it is visible it takes the place of `endAdornment`, so the two don't show together:

```tsx
export const InputWithClearButton = () => {
  const [value, setValue] = useState('')

  return (
    <Input
      value={value}
      onChange={e => setValue(e.target.value)}
      onClear={() => setValue('')}
      placeholder="Search..."
      aria-label="Search"
    />
  )
}
```

<Container>
  <InputWithClearButton />
</Container>

## Error State

The input styles change when the `data-invalid` attribute is present (set automatically by `Field.Root` with `invalid` prop, or manually). `Field.Error` shows only when the field fails validation, so add `match` to show it whenever you set `invalid` yourself:

```tsx
<Field.Root invalid>
  <Field.Label>Email</Field.Label>
  <Input placeholder="user@example.com" />
  <Field.Error match>Invalid email address</Field.Error>
</Field.Root>
```

## With Field

Wrap `Input` in a `Field` for labels, descriptions, and validation:

```tsx
<Field.Root>
  <Field.Label>Username</Field.Label>
  <Field.Description>Choose a unique username</Field.Description>
  <Input placeholder="johndoe" />
</Field.Root>
```
