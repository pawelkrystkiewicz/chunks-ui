# ClearButton

A small circular icon button for clearing or dismissing values. Used internally by `Input` (via `onClear`) and `Chip` (via `onRemove`), but also exported for direct use.

## Import

```tsx
import { ClearButton } from 'chunks-ui'
```

## Basic Usage

```tsx
<ClearButton onClick={() => console.log('Cleared')} />
```

<Container>
  <ClearButton />
</Container>

## Custom Label

Use the `label` prop to override the default accessible label:

```tsx
<ClearButton label="Remove tag" />
```

<Container>
  <ClearButton label="Remove tag" />
</Container>

All other props are forwarded to the underlying `<button>` element.

## Labels

`labels` replaces the built-in English text, for example to translate it. Keys you leave out keep their default from `DEFAULT_CLEAR_BUTTON_LABELS`. `label` and `aria-label` take precedence. See [Labels](/labels).

  definition={generateDefinition({

`
  })}
/>

## Styling

The button renders at `size-6` (24px) with a rounded-full shape. It shows `text-muted-foreground` by default. On hover the icon turns `text-destructive-text` over a faint `bg-destructive/5` background, and the button grows slightly (`hover:scale-105`).

To make it easier to tap, add [`touch-target`](/utilities#touch-target): the hit area grows to 44×44px, and the button's size and the layout stay the same.

```tsx
<ClearButton className="touch-target" />
```
