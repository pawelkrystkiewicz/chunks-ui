# Progress

A progress bar built on Base UI's `Progress` primitive. Supports determinate values and an indeterminate loading state.

## Import

```tsx
import { Progress } from "chunks-ui";
```

## Basic Usage

Pass `value` and `max` to show a determinate progress bar:

```tsx
<Progress.Root value={65} max={100}>
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
</Progress.Root>
```

## Indeterminate

Pass `value={null}` to activate the indeterminate pulse animation. An `animate-*` class on the indicator, such as `data-[indeterminate]:animate-none`, replaces the pulse:

```tsx
<Progress.Root value={null}>
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
</Progress.Root>
```

<ProgressIndeterminateExample />

### Reduced motion

With `prefers-reduced-motion: reduce`, the indeterminate pulse keeps running. It is an essential status indicator, like the [Loader](/components/loader) spinner: without it, an indeterminate bar is a static block that gives no sign of activity. To stop the pulse with reduced motion, add `data-[indeterminate]:motion-reduce:animate-none` to the indicator. The determinate bar does not transition its width, so it jumps to each new value.

## Compound Parts

| Part | Description |
|---|---|
| `Progress.Root` | State container. Holds `value`, `max`, and exposes `data-indeterminate` when no value is set. |
| `Progress.Track` | The background rail. Full-width pill shape. |
| `Progress.Indicator` | Fills the track proportionally. Pulses when indeterminate. |

## Props

All parts accept the props from their corresponding Base UI [`Progress`](https://base-ui.com/react/components/progress#api-reference) sub-components.
