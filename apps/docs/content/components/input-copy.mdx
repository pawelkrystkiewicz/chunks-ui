# InputCopy

A read-only input with an integrated copy button. Composes `Input` and `CopyButton` internally.

## Import

```tsx
import { InputCopy } from "chunks-ui";
```

## Basic Usage

```tsx
<InputCopy value="https://vibekanban.com/invite/abc123" aria-label="Invite link" />
```

<InputCopyBasicExample />

## Editable

The input is read-only by default (`readOnly` defaults to `true`). To let users edit the value, pass `readOnly={false}` and control `value` with `onChange`. The button copies the current value:

```tsx
function EditableInputCopy() {
  const [value, setValue] = useState("PROMO-2024-SUMMER");

  return (
    <InputCopy
      value={value}
      onChange={(e) => setValue(e.target.value)}
      readOnly={false}
      aria-label="Promo code"
    />
  );
}
```

export default Props
`

All other `Input` props are forwarded except `endAdornment` and `onClear` (reserved for the internal `CopyButton`). `readOnly` defaults to `true`. `aria-label` names the input, not the copy button.

## Labels

`labels` replaces the built-in English text, for example to translate it. Keys you leave out keep their default from `DEFAULT_INPUT_COPY_LABELS`. They name the copy button, which reads "Copied" for a moment after a copy. See [Labels](/labels).
