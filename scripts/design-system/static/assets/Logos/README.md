# Logos

The Chunks UI mark: a ring split into three arcs around a square chunk; a diagonal slash cuts the square's bottom-right corner off, on the line through the ring's top-right and bottom-left gaps. Fixed-ink files on a transparent ground, used as the docs navbar does:

- `logo.svg` — black ink. Use on light grounds (`background` in the light theme).
- `logo-dark-mode.svg` — white ink. Use on dark grounds (`background` in the dark theme).
- `logo-small.svg`, `logo-small-dark-mode.svg` — the same mark with a thicker ring, drawn for 24–32px. Use these at 32px and below.

Show it at 30px (the small cut) beside the name "Chunks UI" set in bold `sans`; below about 390px wide, show the mark alone and keep the name for screen readers. The mark is decorative next to the name (`alt=""`). Never recolour it, add a wordmark of your own, or put it on `primary`.
