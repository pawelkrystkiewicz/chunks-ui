# Logos

The Chunks UI mark: a solid disc with a square chunk inside, cut by a diagonal bar. Two fixed-ink files, used as the docs navbar does:

- `logo.svg` — black disc, white square. Use on light grounds (`background` in the light theme).
- `logo-dark-mode.svg` — white disc, black square. Use on dark grounds (`background` in the dark theme).

Show it at 30px beside the name "Chunks UI" set in bold `sans`; below about 390px wide, show the mark alone and keep the name for screen readers. The mark is decorative next to the name (`alt=""`). Never recolour it, add a wordmark of your own, or put it on `primary`.
